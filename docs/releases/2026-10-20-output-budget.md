## 原因与变更范围

工作台实际进程环境中的 `WORKSTATION_DEFAULT_MAX_TOKENS=4096`，与此前源码默认值一致；该上限由原生思考和最终正文共同消耗。复杂任务可能在正文开始前或输出中途耗尽额度，不是增加等待时间就能恢复。

本次将源码 fallback、`.env.example` 与线上单个运行配置统一提高为 **32768（8 倍）**。普通浏览器请求不需要额外参数，仍开启原生深度思考；显式 API 预算和管理员环境配置优先，不静默改写。32768 是上限，不强制生成到上限。两个聊天路由总上下文配置均为 131072，输入加生成预算仍须在上下文内。

没有提示词强迫结束思考、伪造最终答案、自动关闭思考、模型切换或无界重试。已有的 length、空正文、缺终态、异常和主动停止处理保留；`[DONE]` 或 HTTP 200 单独不能当作完成。

修改：`src/lib/chatRequest.ts`、对应测试、`src/app/api/chat/route.test.ts`、`.env.example`、`docs/chat-completion-contract.md`。
